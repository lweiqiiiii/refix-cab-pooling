# Project-local FDE State

This directory contains engagement state for this repository.

The reusable FDE methodology lives at `~/.fde-os/` and should not be copied into this project.

Start with `project_state.md`; update facts, assumptions, risks, decisions, and open questions as evidence changes.

Stage artifacts belong in ../01 Discovery/, ../02 Design/, ../03 Delivery/, and ../04 Operations/.
Record explicit stage-transition approvals in approvals.md; never infer approval.
